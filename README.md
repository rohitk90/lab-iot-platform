# 🚀 Central Laboratory Industrial IoT (IIoT) Data Core Platform

This repository manages the unified, air-gapped data core architecture for the R&D laboratory network. It handles edge ingestion, central message brokering, time-series telemetry storage, and administrative interface proxies across 40 user desktop client nodes.

## 🛠️ Step-by-Step Production Core Rollout

### 1. Provision Permanent Data Storage Anchors
To prevent total data wipes when containers cycle, create structural volumes inside your server file system matching your `.env` target parameters and open appropriate permission loops:

```bash
sudo mkdir -p /var/lib/lab-platform/data/{timescaledb,emqx,redis,minio,grafana}
sudo chmod -R 777 /var/lib/lab-platform/data
```

### 2. Configure Environment Parameters File
Populate a `.env` configuration template in the platform root. Do not hardcode these items down into the repository codebase layout blocks:

```bash
nano .env
```
*(Paste variables covering database endpoints, object repository nodes, passwords, and server persistent mounts).*

### 3. Spin Up the Stack Core
Execute a single container orchestration instruction to automatically download, map, link networks, construct internal databases, and initialize the full application stack in background service mode:

```bash
docker compose up -d
```

### 4. Verify Active System Health Status
Confirm that all 6 central infrastructure service blocks report healthy container operational thresholds:

```bash
docker compose ps
```

## 🛜 Access Topology Paths (For Lab Desktop Users)

Any computer connected to the local air-gapped laboratory network switch can securely open a standard browser and route directly to these interfaces using the central server's static IP address:

* **Grafana Analytic Portals:** `http://<SERVER_IP>` (Managed via NGINX Proxy over default HTTP Port 80. Standard Phase 1A Login: `admin` / `admin`).
* **EMQX Operations Dashboard:** `http://<SERVER_IP>:18083` (For monitoring live MQTT traffic rates and telemetry client channels).
* **MinIO Storage Console:** `http://<SERVER_IP>:9001` (For file tracking interfaces).

## 💾 Local Storage Backup Protocol

A server cron automation daemon calls a backup procedure execution file every night at **2:00 AM**.

* **Database Core:** Captures a deep relational table state slice (`pg_dump`) of the explicit schemas (`platform_data` and `public`), compressing it down onto raw storage arrays to enable instance point recovery.
* **Asset Storage Volumes:** Compresses all persistent file structures inside `/var/lib/lab-platform/data` covering Grafana dashboards, EMQX engine updates, and MinIO content streams.
* **Log Checkups:** Check execution errors via terminal logs: `tail -f /var/log/lab_platform_backup.log`.
